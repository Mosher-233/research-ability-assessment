# 研究能力评价系统 - 项目分析报告

## 一、项目概述

### 1.1 项目简介
这是一个用于大学生研究能力评估的全栈应用系统，基于**多智能体系统（Multi-Agent System）**架构，结合大语言模型（LLM）实现自动化的研究能力评价。系统支持教师创建任务、学生提交证据、AI自动评估并生成报告的完整工作流程。

### 1.2 技术栈

#### 后端技术栈
- **编程语言**：Go 1.20+
- **Web框架**：Gin 1.9.1
- **ORM**：GORM 1.30.0
- **关系型数据库**：MySQL 8.0 / PostgreSQL 14+
- **图数据库**：Neo4j 5.23
- **认证**：JWT（golang-jwt/jwt/v5）
- **配置管理**：Viper
- **LLM集成**：Deepseek API

#### 前端技术栈

- **框架**：Vue 3 + TypeScript
- **构建工具**：Vite 4.4.5
- **UI组件库**：Element Plus 2.3.9
- **路由**：Vue Router 4.2.4
- **HTTP客户端**：Axios 1.4.0
- **图表库**：ECharts 6.0.0

### 1.3 核心功能

1. **用户认证与角色管理**：支持教师和学生两种角色
2. **任务管理**：教师创建、分配研究任务
3. **证据管理**：学生提交研究证据
4. **AI能力推理**：LLM主导多维度评估（含证据引用溯源），支持PDF/DOCX/TXT/Markdown文件内容提取
5. **报告生成**：自动生成评估报告和可视化
6. **知识图谱存储**：使用Neo4j存储学生能力图谱

### 2.2 后端模块详解

#### 2.2.1 internal/agent - 多智能体系统核心

这个包是系统的核心，实现了研究能力评价的AI Agent架构：

| 文件 | 功能描述 |
|------|---------|
| `control_unit.go` | 控制单元，协调整个评估流程：证据收集 → 能力推理 → 结果存储 → 知识图谱更新 |
| `evidence_agent.go` | 证据Agent：LLM优先分类与等级评定（规则兜底），PreprocessEvidence/ClassifyEvidence/ExtractKBMInfo |
| `inference_agent.go` | 能力推理Agent：LLM主导多维推理（含Rubrics量规），提取evidence_quotes生成CitationInfo |
| `feedback_agent.go` | 反馈生成Agent：LLM生成个性化改进建议（含规则兜底），结构化JSON输出 |
| `logic_unit.go` | 逻辑单元：规则兜底计算（KBMLevel×20→维度平均→等权重加权） |
| `storage_unit.go` | 存储单元：结果持久化、Neo4j图谱更新、证据引用记录存储 |

**关键能力维度映射（KBM → 维度）：**

- 文献检索策略、文献综述质量、文献批判性分析 → 文献综述
- 实验方案合理性、变量控制、实验实施质量 → 研究设计
- 数据分析方法选择、结果解释准确性 → 数据分析
- 问题提出新颖性、解决方案原创性 → 批判性思维

#### 2.2.2 internal/service - 业务逻辑层

| 文件 | 功能描述 |
|------|---------|
| `auth_service.go` | 认证服务：用户注册、登录、JWT生成与验证 |
| `task_service.go` | 任务服务：任务CRUD、学生任务分配、状态管理 |
| `evidence_service.go` | 证据服务：证据提交、查询、管理 |
| `inference_service.go` | 推理服务：核心评分逻辑、LLM集成、报告生成（包含简化算法和LLM增强两种模式） |
| `report_service.go` | 报告服务：生成学生报告、任务报告、班级统计 |

**推理服务核心流程：**
1. 获取学生证据
2. 按维度分组证据
3. 计算各维度得分（支持简化算法和LLM两种方式）
4. 计算总体得分
5. 生成推理理由
6. 存储结果

#### 2.2.3 internal/handler - HTTP接口层

| 文件 | 功能描述 |
|------|---------|
| `auth_handler.go` | 认证接口：POST /register, POST /login, GET /user/info |
| `task_handler.go` | 任务接口：创建任务、获取任务列表、分配任务等 |
| `evidence_handler.go` | 证据接口：提交证据、获取证据列表 |
| `result_handler.go` | 结果接口：获取推理结果、生成报告 |

#### 2.2.4 internal/models - 数据模型

| 文件 | 描述 |
|------|------|
| `user.go` | 用户模型（User）、教师模型（Teacher）、学生模型（Student） |
| `task.go` | 任务模型（Task）、学生任务关联模型（StudentTask） |
| `evidence.go` | 证据模型（Evidence） |
| `result.go` | 推理结果模型（InferenceResult）、维度得分模型（DimensionScore） |
| `feedback.go` | 反馈模型 |
| `report.go` | 报告模型 |

#### 2.2.5 internal/repository - 数据访问层

- **postgres/**：MySQL关系型数据库操作（包名沿用"postgres"，实际后端为MySQL）
  - `user_repo.go`：用户数据操作
  - `task_repo.go`：任务数据操作
  - `result_repo.go`：推理结果数据操作

- **neo4j/**：Neo4j图数据库操作
  - `graph_repo.go`：学生节点、维度节点、得分关系的创建和查询

#### 2.2.6 internal/llm - 大语言模型集成

| 文件 | 功能描述 |
|------|---------|
| `client.go` | LLM客户端：OpenAI兼容API封装（支持response_format JSON模式），120s超时 |
| `parser.go` | 结果解析器：逐行解析LLM返回的结构化反馈文本 |

#### 2.2.7 internal/middleware - Gin中间件

| 文件 | 功能描述 |

| `cors.go` | CORS跨域中间件：处理跨域请求 |
| `logging.go` | 日志中间件：记录请求日志 |

| `pkg/cache` | Redis缓存（优雅降级，连接失败时自动跳过） |

### 摘要

随着AI技术的快速发展，传统的大学生研究能力评价方式面临着效率低、主观性强、难以规模化等挑战。本文设计并实现了一个基于多智能体系统（Multi-Agent System）和大语言模型（Large Language Model, LLM）的研究能力评价平台。该平台采用Go + Vue3全栈架构，结合MySQL关系型数据库和Neo4j图数据库，实现了任务管理、证据收集、AI智能评估、报告生成等完整功能。系统的核心是一个模块化的多智能体架构，包括证据收集Agent、能力推理Agent、反馈生成Agent等，通过控制单元协调工作。同时，系统集成了Deepseek大语言模型，提供增强的评估能力。实验结果表明，该平台能够高效、客观地评价大学生的研究能力，具有良好的可扩展性和实用价值。
